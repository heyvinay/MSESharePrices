MSESharePrices

A static historical-quote feed for Malta Stock Exchange (MSE) listed securities, published as JSON so it can be read directly by Portfolio Performance's JSON quote-feed provider. Refreshed automatically via GitHub Actions.

Available feeds

  • json/BOV.json — Bank of Valletta plc

Portfolio Performance setup

In the security's "Historical Quotes" tab, choose provider JSON and set:

Feed URLhttps://heyvinay.github.io/MSESharePrices/json/BOV.json
Path to Date$[*].date
Path to Close$[*].close

Source

Data is derived from MSE's published Daily Trading Summary yearly archive. See the repository's docs/ folder for the full spec, architecture notes, and known limitations.
